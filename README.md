# Device Info

فری اسٹوریج اور فون کی معلومات، جو آپ کی چنی ہوئی چیزیں اسٹیٹس بار کے نیچے (نوٹیفکیشن میں) دکھاتی ہے۔ پس منظر میں چلتی ہے اور فون چلتے ہی خود شروع ہو جاتی ہے۔

## ایپ کیا کرتی ہے
- معلومات ٹیب (لائیو، ہر 2 سیکنڈ): خالی اسٹوریج (کل اور استعمال فیصد)، SD کارڈ (اگر ہو)، RAM، بیٹری (فیصد، چارجنگ، درجہ حرارت، وولٹ، صحت)، نیٹ ورک کی قسم اور ڈاؤن/اپ رفتار، آن ٹائم، فون ماڈل اور اینڈرائیڈ، CPU (کور، ABI، کرنل)، اسکرین (ریزولوشن، dpi، Hz)، سینسرز کی تعداد۔
- اسٹیٹس بار ٹیب: ایک سوئچ سے نوٹیفکیشن آن/آف؛ ہر چیز الگ آن/آف؛ اسٹیٹس بار کے چھوٹے آئیکن میں کیا لکھا آئے (مثلاً 45G خالی اسٹوریج، 85% بیٹری، 1.2M رفتار)؛ اپڈیٹ کا وقفہ 2/5/10/30 سیکنڈ؛ "فون چلتے ہی خود شروع" کا آپشن۔
- نوٹیفکیشن کھولیں تو منتخب سب معلومات کی تفصیل ملتی ہے۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `DeviceInfo-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں؛ انٹرنیٹ نہیں۔ پرمیشنز: نوٹیفکیشن، فارگراؤنڈ سروس، بوٹ پر آغاز، نیٹ ورک کی حالت۔
- اسکرین بند ہو تو اپڈیٹ رک جاتی ہے (بیٹری بچانے کو)؛ اسکرین کھلتے ہی تازہ ہو جاتی ہے۔
- اینڈرائیڈ 13+ پر نوٹیفکیشن کی اجازت لازمی ہے۔ صارف نوٹیفکیشن ہٹا دے تو سروس چلتی رہتی ہے، ایپ کھولنے پر نوٹیفکیشن لوٹ آتا ہے۔
- Xiaomi، Oppo، Vivo، Huawei وغیرہ پر "Autostart" اور بیٹری کی پابندی ہٹانا ضروری ہے، ورنہ بوٹ پر سروس شروع نہ ہو۔
- اسٹیٹس بار کے آئیکن میں صرف چھوٹا متن (جیسے 45G) آ سکتا ہے؛ پوری تفصیل نوٹیفکیشن میں ہوتی ہے۔
